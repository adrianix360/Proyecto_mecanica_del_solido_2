# 03 · Planos de montaje (v02)

Cinco láminas A0 a escala 1:1.

| Lámina | Contenido |
|---|---|
| WA-01 | Alzados y plantas |
| WA-02 | Despiece de miembros |
| WA-03 | Cartelas |
| WA-04 | Cuerda inferior, vigas de piso, puntales, arriostres y placas |
| WA-05 | Detalles y cantidades |

- `pdf/`: cada lámina por separado y el juego completo `WA_Juego_v02.pdf`.
- `dxf/`: el mismo dibujo en DXF, para abrirlo en AutoCAD u otro programa de dibujo.
- `vista_previa/`: imágenes de referencia.
- `QA_v02.md`: informe de verificación de los planos.

La versión v02 incorpora la corrección H-05 (cartelas superiores al ras de la cuerda y altura total de ≈ 154 mm) respecto de la v01. **Aviso:** los planos son material original protegido; no se autoriza imprimirlos ni usarlos para construir una réplica (ver la licencia).
