# 04 · Despiece y corte para Silhouette Cameo 5 Alpha (v02)

Despiece completo del puente distribuido en tapetes de 235 × 300 mm: cada miembro o nudo completo queda en un solo tapete.

| Archivo | Descripción |
|---|---|
| `dxf/T00_PRUEBA.dxf` | Tapete de prueba |
| `dxf/T01_v02.dxf` a `T11_v02.dxf` | Tapetes de corte |
| `dxf/T12_RETENIDO_H01_v02.dxf` | Vigas de piso VP2 a VP5, retenidas por la observación H-01 de la revisión de diseño |
| `CONTROL_TAPETES_v02.pdf` | Control de tapetes (A3, 1:1, con casillas de verificación) |
| `GUIA_SILHOUETTE_v02.md` | Guía de uso en Silhouette Studio |
| `INVENTARIO_CORTE_v02.xlsx` / `.csv` | Inventario de las 269 hojas de piezas |
| `QA_corte_v02.md` | Verificación del despiece (8 de 8 comprobaciones) |
| `vista_previa/` | Imágenes de cada tapete |

Los archivos DXF están en formato R12, que Silhouette Studio abre en su edición básica.
